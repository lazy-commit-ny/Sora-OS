## English

**Sora-OS** is a fast, modern, general-purpose PC operating system featuring a clean macOS-inspired top menu bar and dock interface, smart memory-accelerated boot, seamless Wi-Fi auto-reconnect, and built-in AI integration.

### Key Features
- **Fast Boot & Memory Optimization:** Prefetches critical boot data into RAM, uses zram compressed caching, and suspends background tasks for rapid startup and instant wake.
- **Smart Wi-Fi & Connectivity:** Guided Wi-Fi setup on first boot (and after factory reset) with automatic credential saving and auto-reconnect on subsequent boots, plus Bluetooth support.
- **Refined Desktop UI:** Clean top menu bar (Wi-Fi, Bluetooth, and system controls on the top right) and bottom app dock with smooth GPU-accelerated visuals.
- **Modern Essentials:** Window snapping, virtual desktops, automatic updates via GitHub Releases, firewall protection, and accessibility tools.
- **Built-in AI Assistant:** OS-level AI integration for text assistance, image editing, and natural-language local file search.

### How to Download & Run
1. Go to the **Releases** page of this repository and download the latest `.iso` file.
2. Write the `.iso` image to a USB flash drive using a tool such as **Rufus** or **balenaEtcher**.
3. Insert the USB drive into your 64-bit PC and boot from the USB drive via the BIOS/UEFI boot menu.
4. On first boot, select your Wi-Fi network and enter the password to connect and save it automatically.

## 日本語

**Sora-OS** は、Macを意識した洗練された上部メニューバー＆ドックのUI、メモリ最適化による高速起動、初回案内付きのWi-Fi自動保存・再接続、そしてOS統合型AIを備えた一般公開向けPC用OSです。

### 主な特徴
- **メモリ活用による高速起動・快適動作:** 起動データのメモリ先読み（プリフェッチ）、zram圧縮キャッシュ、高速スリープ復帰により、起動から操作まで軽快に動作します。
- **スマートなWi-Fi・通信管理:** 初回起動時（および初期化後）はWi-Fi接続案内を表示し、一度接続したネットワークは自動保存して2回目以降に自動再接続します。Bluetoothにも対応しています。
- **Mac風のすっきりしたUI:** 画面上部にメニューバー（右上にWi-Fi・Bluetooth等の管理アイコンを配置）、下部にドックを備えた視認性の高いデスクトップ環境です。
- **現代のPCに求められる実用機能:** ウィンドウ分割（スナップ）、仮想デスクトップ、GitHub Releases連携による自動アップデート、セキュリティ保護、アクセシビリティ機能を搭載しています。
- **OS標準のAI統合:** 文章作成補助、画像編集、自然な日本語でのPC内ファイル検索などをOSレベルでサポートします。

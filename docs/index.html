Sora-OS System Overview

高速起動 & zramメモリ最適化

起動データの先読みとzram圧縮キャッシュにより、限られたメモリ環境でも起動から操作まで軽快に動作します。

スマートWi-Fi自動接続

初回起動時（および初期化後）にWi-Fi設定案内を表示。一度接続したネットワークは自動保存され、次回以降自動再接続します。

洗練されたデスクトップUI

画面上部のシステムメニューバーと下部のアプリドックを採用し、直感的で視認性の高い操作体験を提供します。

OS標準のAI統合

文章作成の補助や画像編集、自然な言葉でのローカルファイル検索をOSレベルでサポートします。

ダウンロードと起動手順

  1. 1
    ISOイメージを取得
    GitHub Releases から最新の Sora-OS-x86_64.iso をダウンロードします。
  2. 2
    USBメモリへ書き込み
    Rufus または balenaEtcher などの書き込みツールを使い、空のUSBメモリにISOを書き込みます。
  3. 3
    USBからPCを起動
    64bit対応PCにUSBメモリを挿して電源を入れ、BIOS / UEFI のブートメニューからUSBドライブを選択して起動します。
  4. 4
    初回Wi-Fiセットアップ
    初回起動時は案内に従ってSSIDとパスワードを入力すると、接続と自動再接続設定が完了します。
